GSolders Store - Аннотация проекта
GSolders Store - тестированиt интернет-магазина военной миниатюры и солдатиков.

Структура проекта

GSolders/
├── base/           # Базовые классы и утилиты
├── pages/          # Page Object Model - страницы приложения
├── tests/          # Тестовые сценарии
└── configuration/  # Файлы конфигурации

Ключевые модули
1. Base Layer (base/)
base_class.py - базовый класс для всех страниц
Содержит общие методы для работы с веб-элементами


2. Page Objects (pages/)
main_pages.py - главная страница магазина

catalog_pages.py - страница каталога товаров

men_body_pages.py - страницы тел солдатиков

men_head_pages.py - страницы голов солдатиков

body_parts_pages.py - страницы частей тела

solders_pages.py - страницы готовых солдатиков

our_military_pages.py - страница отечественных солдатиков

figure_accessories_pages.py - страницы аксессуаров

cart_buy_pages.py - корзина и оформление заказа

3. Tests (tests/)
test_buy_product.py - тестовые сценарии покупки товаров

Реализован сценарий выбора комплекта снаряжения покупки телоида и скульпта головы, проверка артикулов, наименования, цен по отдельности и общей цены.
Ввод данных для оформления заказа не реализовался.

PS хочу отметить отдельную сложность с финальной страницей товара, тк сохраненные ранее значения не подходили для проверки
